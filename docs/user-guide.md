# Lab Calendar 사용 안내

랩실 일정과 회의비 사용 내역을 한 화면에서 보는 웹 캘린더입니다. 설치할 것은 없고
브라우저로 주소를 열면 됩니다. 휴대폰에서도 같은 주소로 쓸 수 있습니다.

- 주소: https://lab-calendar.cloud

---

## 1. 접속하기

주소를 열면 비밀번호를 묻는 화면이 먼저 나옵니다. 개인 계정은 없고 **랩실 공용
비밀번호 두 개**로 들어갑니다. 어느 것을 넣느냐에 따라 할 수 있는 일이 달라집니다.

| 비밀번호 | 할 수 있는 일 |
| --- | --- |
| 편집용 | 전부 — 일정 등록·수정·삭제, 과제 관리, 카드 내역 보기와 올리기 |
| 조회용 | 보기만 — **카드/경비 내역은 아예 보이지 않습니다** |

조회용은 외부 자문 위원이나 출장 중인 교수진에게 화면을 공유할 때 쓰는 것입니다.
지출 내역이 빠지므로 주소와 조회용 비밀번호를 함께 알려 주어도 됩니다.

비밀번호는 담당자에게 문의하세요. 한 번 넣으면 브라우저를 닫았다 열어도 유지되고,
오른쪽 위 **나가기**를 누르면 풀립니다. 공용 컴퓨터에서 썼다면 나가기를 눌러 주세요.

조회용으로 들어오면 화면 위에 `조회 전용` 표시가 붙고 등록 폼이 보이지 않습니다.
고칠 일이 있는데 폼이 없다면 조회용으로 들어온 것입니다.

## 2. 달력 보기

가운데가 이번 달 달력이고, 왼쪽이 제어 영역입니다. 휴대폰처럼 화면이 좁으면 왼쪽이
접히고, 왼쪽 위 메뉴 버튼(☰)으로 펼칩니다.

### 일정의 종류

일정은 세 가지로 나뉘고 색과 모양으로 구분됩니다. 색만으로 구분하지 않는 이유는
색을 구별하기 어려운 사람도 함께 보기 때문입니다.

| 표시 | 종류 | 무엇이 들어오나 |
| --- | --- | --- |
| ◆ 빨강 | 과제/연구 관리 | 과제 마감과 자동 생성된 준비 기간 |
| ● 초록 | 랩실 주기적 일정 | 랩미팅, 장비 점검처럼 직접 넣는 일정 |
| ■ 파랑 | 카드/경비 사용 | 회의비 장부에서 들어온 지출 |

왼쪽 **카테고리 필터**에서 체크를 끄면 그 종류가 달력에서 빠집니다. 필터는 주소에
남으므로, 원하는 조합으로 걸러 둔 주소를 그대로 공유해도 됩니다.

### 일정 자세히 보기

달력의 막대를 누르면 팝업이 열려 기간, 참석 인원, 메모를 볼 수 있습니다. 카드 지출
막대는 마우스를 올리기만 해도 참석 인원이 뜹니다 — 여러 건을 훑을 때 일일이 누르지
않아도 됩니다.

한 칸에 일정이 많으면 `+N개 더 보기`로 접힙니다. 눌러서 펼칠 수 있습니다.

## 3. 일정 등록하고 고치기

편집용으로 접속해야 보입니다.

### 등록

왼쪽 **일정 등록**에서 항목 유형을 고르고 채웁니다. 유형에 따라 가운데 칸의 의미가
달라집니다.

| 유형 | 가운데 칸 | 예 |
| --- | --- | --- |
| 과제/연구 관리 | 제출 단계 | 연차보고서 |
| 랩실 주기적 일정 | 담당 연구원 | 홍길동 |
| 카드/경비 사용 | 구분 | 점심, 저녁, 초과 |

시작일과 종료일을 다르게 주면 여러 날에 걸친 막대가 됩니다. 하루짜리는 두 날짜를
같게 두면 됩니다.

참석 인원은 쉼표로 구분해 적거나, 아래 명단에서 이름을 눌러 넣습니다. 명단에 없는
외부 인원은 직접 입력하면 됩니다.

### 고치기와 지우기

막대를 눌러 팝업을 열고 **수정** 또는 **삭제**를 누릅니다. 달력에서 막대를 끌어
옮기거나 끝을 잡아 늘여도 바로 저장됩니다.

**자동으로 만들어진 일정은 고칠 수 없습니다.** 과제에서 생성된 준비 기간과 장부에서
들여온 카드 지출이 그렇습니다. 여기서 고쳐도 다음에 다시 만들어지면서 되돌아가기
때문에, 팝업이 어디를 고쳐야 하는지 알려 줍니다.

## 4. 과제와 준비 기간 자동 생성

위쪽 **과제 관리** 메뉴입니다.

과제를 등록할 때 **제출 마감일**과 **준비 기간(일)** 을 넣으면, 마감일에서 그만큼
거슬러 올라간 날부터 마감일까지 `[작성 요망] …` 막대가 달력에 저절로 생깁니다.
준비 기간은 0~182일 사이의 날수이고 기본값은 21일(3주)입니다.

마감일이나 준비 기간을 고치면 막대도 따라 움직입니다. 막대를 직접 지울 필요는
없습니다.

**캘린더에 표시** 체크를 끄면 그 과제의 막대가 달력에서 내려갑니다. 끝난 과제를
지우지 않고 숨길 때 쓰세요. 지우면 기록이 사라지지만, 끄면 과제 관리 화면에는
남습니다.

### D-Day

달력 위에 가장 급한 과제 세 건이 남은 일수와 함께 뜹니다. 눌러서 그 날짜로 이동할 수
있습니다. 마감이 가까워진 과제는 붉게 강조되고, 하루에 한 번 화면 앞에 알림이 뜹니다.

남은 일수는 **서버가 계산한 값**입니다. 보는 사람의 컴퓨터 시계가 틀어져 있어도 모두
같은 숫자를 봅니다.

## 5. 구성원 명단

위쪽 **구성원** 메뉴에서 이름을 등록해 두면, 일정을 만들 때 참석자와 담당 연구원을
명단에서 눌러 넣을 수 있습니다. 로그인 계정이 아니라 이름 목록일 뿐입니다.

랩실을 떠난 사람은 지우지 말고 비활성으로 두세요. 지난 일정의 참석 기록은 남아야
합니다. 실제로 어딘가에 쓰이고 있는 이름은 삭제가 거절됩니다.

## 6. 카드 내역 올리기

위쪽 **카드 내역** 메뉴이며 편집용으로만 보입니다.

회의비 장부는 지금 쓰시는 구글 시트를 그대로 씁니다. **양식을 바꿀 필요가 없습니다.**
달라지는 것은 그 파일을 가끔 이 화면에 올려 준다는 것뿐입니다.

### 올리는 방법

1. 구글 시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)** 로 받습니다.
2. 카드 내역 화면에서 **파일 선택** 으로 그 파일을 고릅니다.
3. **미리보기** 가 뜹니다. 달마다 몇 건이 새로 들어오고 몇 건이 사라지는지 보여줍니다.
4. 확인한 뒤 **반영** 을 누르면 달력에 나타납니다.

올리는 주기는 정해져 있지 않습니다. 파일 전체를 매번 올려도 바뀐 것이 없으면 아무
일도 일어나지 않습니다.

### 읽어 가는 칸

시트 이름이 `2026년 9월` 처럼 연도와 달로 된 시트만 읽습니다. `복사용 시트` 나 연도가
없는 `7월` 같은 시트는 건너뛰고, 건너뛴 목록을 미리보기에 적어 줍니다.

| 열 | 내용 | 달력에서 |
| --- | --- | --- |
| A | 날짜(일) | 일정 날짜. 같은 날 두 번째 줄부터는 비워 두셔도 됩니다 |
| B | 과제 | 막대에 표시 |
| C | 인원 | 마우스를 올리면 이름과 총 인원수 |
| D | 구분 (점심/저녁/초과) | 막대에 표시 |
| E 이후 | 메모 등 | 읽지 않습니다 — 무엇을 적으셔도 됩니다 |

달력에는 `BRL: 저녁` 처럼 나오고, 구분이 비어 있으면 `BRL` 만 나옵니다.

### 미리보기에서 꼭 보실 것

**사라짐** 숫자입니다. 이 서비스는 달 단위로 장부와 달력을 맞춥니다. 파일에서 지워진
줄은 반영과 함께 달력에서도 사라집니다. 시트를 잘못 편집한 파일을 올리면 지난 기록이
없어질 수 있으니, 사라짐이 0이 아닌 달은 한 번 더 확인해 주세요.

**오류로 해당 월 전체 유지** 라고 적힌 달은 그 달에 읽을 수 없는 줄이 있어 통째로
건드리지 않은 것입니다. 나머지 정상인 달은 그대로 반영됩니다. 어느 시트 몇 번째 줄이
문제인지 미리보기에 나오니, 그 줄을 고친 뒤 다시 올리시면 됩니다.

파일에 없는 달은 손대지 않습니다. 올해 시트만 남긴 파일을 올려도 작년 기록은 그대로
있습니다.

### 자주 나오는 문제

| 미리보기가 말하는 것 | 뜻 |
| --- | --- |
| 과제명이 비어 있습니다 | B열이 빈 줄입니다. 그 달 전체가 보존됩니다 |
| 시트 이름에 연도가 없습니다 | `7월` 처럼 연도가 없어 어느 해인지 알 수 없습니다 |
| 참석자 원문을 그대로 나누지 못했습니다 | 이름을 나눈 결과가 원문과 달라, 원문을 메모에 남겼습니다 |

아래 **최근 업로드** 에 누가 언제 무엇을 올렸는지 남습니다. 같은 파일을 두 번 올리는
일을 줄이려고 둔 것입니다.

## 7. 막혔을 때

**달력이 비어 보입니다.** 카테고리 필터가 꺼져 있는지 왼쪽에서 확인해 주세요.

**카드 지출이 안 보입니다.** 조회용 비밀번호로 들어오면 보이지 않습니다. 화면 위에
`조회 전용` 표시가 있는지 보세요.

**장부에 적었는데 달력에 없습니다.** 카드 내역은 파일을 올려야 들어옵니다. 마지막
업로드 이후에 적으신 것이라면 파일을 다시 올려 주세요.

**고치려는데 수정 버튼이 없습니다.** 자동으로 만들어진 일정입니다. 준비 기간은 과제
관리에서 마감일이나 준비 기간을 고치고, 카드 지출은 엑셀 원본을 고쳐 다시 올립니다.

**화면이 이상합니다.** 새로고침을 한 번 해 보시고, 그래도 같으면 어느 화면에서 무엇을
누르셨는지와 함께 담당자에게 알려 주세요.
