# 대한민국 공휴일 표시

날짜 머리글에 공휴일 이름과 빨간 날짜를 표시한다. 일정 이벤트가 아니므로 카테고리 필터, 상세 팝업, 드래그/수정/삭제의 대상이 아니며 DB에 쓰지 않는다. 조회/편집 등급 모두 같은 표시를 사용한다.

## 제공 범위와 유지보수

2020~2027년 확인된 목록을 앱에 포함한다. 2028년 이후는 현행 공휴일·대체공휴일 규칙으로 계산하여 연도별로 캐시한다. 인터넷 조회나 인증키 없이 동작한다. 미래 연도에는 예정 날짜 안내를 표시한다. 임시공휴일·선거일은 추측하지 않는다. 공식 발표나 법령 변경 시 목록과 계산 규칙을 갱신하고 배포해야 한다. 공식 목록의 자동 수집은 구현하지 않았다.

양력 공휴일은 앱의 날짜 표현 범위 내에서 미래 연도 제한을 두지 않는다. 한국 음력 변환 라이브러리는 2050년까지 지원하므로 2051년 이후에는 양력 공휴일만 표시하고 음력 공휴일 누락을 명시한다. 이 범위에서 대체공휴일 계산도 음력 공휴일과의 겹침을 반영할 수 없다. 2020년 이전에는 현행 규칙을 소급하지 않고 미제공 안내를 표시한다.

## 출처 (2026-10-03 확인)

- 미래 날짜 변환: https://github.com/usingsky/korean_lunar_calendar_js (korean-lunar-calendar 0.4.0, MIT, 한국 음력·양력 자료 2050년까지).
- 현행 대체공휴일 규칙: https://www.law.go.kr/lsInfoP.do?lsiSeq=285779&viewCls=lsRvsDocInfoR (제3조). 설날·추석은 일요일 또는 평일의 다른 공휴일과 겹칠 때, 기타 적용 대상은 토·일요일 또는 평일의 다른 공휴일과 겹칠 때 적용한다. 신정·현충일 자체에는 대체휴일을 적용하지 않는다.
- 2020~2025년 날짜와 당시 대체공휴일 적용 범위: https://github.com/vacanza/holidays/blob/dev/tests/countries/test_south_korea.py (MIT). 설날·추석 연휴 명칭은 기존 화면과 동일하게 정규화했다. BANK 전용 근로자의날은 제외했다. 2025년 어린이날·부처님오신날 중복은 두 이름을 모두 표시한다.
- 한국천문연구원 특일 정보: https://www.data.go.kr/data/15012690/openapi.do
- 원본 API 데이터를 제공하는 공개 사본: https://github.com/raki-1203/korean-holidays/tree/main/holidays (2026.json, 2027.json). 사본에는 노동절과 관련 대체공휴일 등이 빠져 있어 그대로 사용하지 않았다.
- 우주항공청 2027년 월력요항: https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431
- 인사혁신처 노동절·제헌절 지정 발표: https://openminister.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?boardId=bbs_0000000000000029&cntId=4250&mode=view

공식 발표에 따라 2026-05-01 노동절, 2027-05-01 노동절, 2027-05-03 노동절 대체공휴일, 2027-07-19 제헌절 대체공휴일을 보완했다. 일반 일요일은 이름 있는 공휴일 목록에 추가하지 않는다.
